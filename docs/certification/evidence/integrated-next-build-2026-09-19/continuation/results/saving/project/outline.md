# Participant worksheet outline

**Format:** Two-page printed worksheet for a 40-minute session that works
without dependable internet or a display. The workshop has 10 participants.
[Source: Harbor workshop brief](brief.md)

## Page 1 — Separate observations from assumptions

- Short fictional equipment-maintenance report excerpt, with space to annotate.
- Prompt: “What does the report directly say?”
- Two-column response area: **Observation** / **Assumption or inference**.
- One prompt to mark the words or details that support each observation.

## Page 2 — Compare, discuss, and apply

- Prompt: “Which assumptions need checking, and what evidence would help?”
- Space for each participant to write one question for the group.
- Small pair/share section: compare one observation and one assumption.
- Closing box: one practice the participant will use when reading a maintenance
  report.
