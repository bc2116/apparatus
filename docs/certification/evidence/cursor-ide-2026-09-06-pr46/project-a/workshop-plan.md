# Practice Workshop Plan

## Confirmed format

- Run two sessions, with no more than 12 places in each session.
- Schedule a water break after the first 45 minutes.
- Keep the venue listed as undecided until it is confirmed.

Source: [Practice workshop source](source.md).

## Draft session flow

1. Welcome, objectives, and orientation.
2. Facilitated practice for the first 45 minutes.
3. Water break (duration to be confirmed).
4. Further practice, questions, and closing recap.

The activities and all timings except the break point are provisional because the source does not specify them.
