## Session outline

Use the same shape for both sessions until a fuller agenda exists.

1. Open the session and confirm attendance against the 12-place cap.
2. Run the session work.
3. Pause for a water break at the 45-minute mark.
4. Resume and close the session.

Do not treat the 45-minute mark as the end of the session. The source only times the break, not the full length.
