# Practice Workshop — Facilitator's Guide

Source: `project-a/source.md`

Purpose: a short, reusable guide for whoever facilitates this workshop the
next time it runs. Constraints below are cited to the source; anything not
stated there is left open rather than guessed.

## Before the session

- Plan for **two sessions, 12 places each** (24 places total) (`source.md:3`).
- Confirm the **venue** before advertising or scheduling — the source does
  not establish one, so treat it as unresolved until confirmed each time this
  workshop is run (`source.md:3`).

## Running each session

- Give a **water break after 45 minutes** into the session (`source.md:3`).
  The source states only when the break starts, not how long it lasts, so
  set a break length using your own judgment on the day.

## Optional suggested activities

*(Not in the source — offered as reusable facilitation ideas only; adapt or
skip as needed.)*

- Opening round: quick round-robin so the 12 participants introduce
  themselves before the workshop starts.
- Post-break check-in: a short recap after the water break to re-orient
  the group before continuing.
- End-of-session feedback: a brief verbal or written check for what to
  carry into the next run of the workshop.

## Left unresolved (confirm fresh each time)

- Venue/location.
- Total session length and start/end times (only the 45-minute mark before
  the break is fixed).
- Water break duration.
- Dates or times.
- Topic/curriculum content, materials needed, and who facilitates.
- Registration process or audience/eligibility for the 12 places per session.
