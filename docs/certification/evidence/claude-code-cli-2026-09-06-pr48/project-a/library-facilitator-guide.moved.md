# Practice Workshop — Facilitator's Guide (for a future organizer)

Source: `project-a/source.md`

Purpose: a reusable reference for whoever organizes and facilitates this
workshop next. Facts below are cited to the source; suggestions and unknowns
are labeled as such rather than presented as settled.

## Facts from the source

- Two sessions, 12 places each (24 places total) (`source.md:3`).
- A water break comes after 45 minutes into each session — the source states
  only when the break starts, not how long it lasts (`source.md:3`).
- The venue is undecided (`source.md:3`). Do not schedule around a venue
  until it is confirmed for that run of the workshop.

## Suggestions (not in the source — adapt or skip)

- Confirm the venue as an early planning step, since it must be resolved
  fresh each time this workshop runs.
- Set a water break length using your own judgment on the day, since the
  source fixes only the 45-minute start point.
- Opening round: a quick round-robin so participants introduce themselves
  before the session starts.
- Post-break check-in: a short recap after the water break to re-orient the
  group before continuing.
- End-of-session feedback: a brief verbal or written check for what to carry
  into the next run of the workshop.

## Unknown / left open (confirm fresh each time)

- Venue/location.
- Total session length and start/end times (only the 45-minute mark before
  the break is fixed).
- Water break duration.
- Dates or times.
- Topic/curriculum content, materials needed, and who facilitates.
- Registration process or audience/eligibility for the 12 places per session.
