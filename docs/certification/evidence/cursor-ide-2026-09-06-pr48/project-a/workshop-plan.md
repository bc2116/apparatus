# Practice Workshop Plan

## Format and capacity

- Run two sessions, each with a maximum of 12 participants ([source](./source.md)).
- In each session, schedule a water break after 45 minutes ([source](./source.md)).
- Venue: undecided; confirm before participant communications are issued ([source](./source.md)).

## Session outline

1. Welcome, introductions, and session objectives.
2. Facilitated workshop activities.
3. Water break after 45 minutes.
4. Resume activities and close with questions and next steps.

Exact timings beyond the water break cannot yet be set because the total session duration is not provided.
