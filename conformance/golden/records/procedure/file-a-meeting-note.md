---
schema: apparatus/procedure@v0
title: File a meeting note
intent: Use when the user shares meeting notes that should be kept and filed.
---
1. Ask which effort in Projects/ the note belongs to; create the folder if it
   is new.
2. Save the note there with a kebab-case filename.
3. Add any durable facts to Memory/Facts/, one fact per file, citing the note
   as the source.
4. If a commitment involves a person, update their page in Memory/People/.
5. Take a snapshot.
