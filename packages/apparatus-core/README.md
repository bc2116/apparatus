# apparatus-core

Core package for [Apparatus](https://github.com/bc2116/apparatus) — the governed
workspace for agentic knowledge work.

This package will provide the `apparatus` command: workspace scaffolding,
validators, the render pipeline, memory and Library operations, snapshots, and
the machine report. The CLI arrives in a later planned change; today the package
is a version stub that anchors the uv workspace and CI.
